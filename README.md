# The Picture Org(anizer) Homebrew tap

Mac apps from [The Picture Org(anizer)](https://thepictureorg.com/tools), signed and notarized by The Picture Org LLC.

```sh
brew install thepictureorgllc/tap/sweepwell
brew install thepictureorgllc/tap/datewell
```

| App | What it does | Price |
| --- | --- | --- |
| [Datewell](https://thepictureorg.com/datewell) | Sets each photo's Date Taken from its file name, a date stamp or a printed date | 21-day trial, then $29 |
| [Matchwell](https://thepictureorg.com/matchwell) | Finds duplicate photos, keeps the best copy and merges the details from the others | 21-day trial, then $49 |
| [Pivotwell](https://thepictureorg.com/pivotwell) | Finds sideways and upside-down photos and turns copies, never your originals | 21-day trial, then $29 |
| [Sortwell](https://thepictureorg.com/sortwell) | Reads divider cards in a folder of scans and moves each batch into its own folder | 21-day trial, then $49 |
| [Spoolwell](https://thepictureorg.com/spoolwell) | Checks, merges, trims, splits, titles and re-dates captured home video | 21-day trial, then $49 |
| [Squarewell](https://thepictureorg.com/squarewell) | Finds every photo on a scan, straightens it and sets a clean crop | 21-day trial, then $49 |
| [Sweepwell](https://thepictureorg.com/sweepwell) | Finds and removes empty folders on photo drives | Free |

Apple silicon Macs, macOS 13 or later. More apps are added as they are listed. Paid apps run as a free 21-day trial,
then need a license key from [thepictureorg.com/tools](https://thepictureorg.com/tools#buy).
