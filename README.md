# The Picture Org(anizer) Homebrew tap

Mac apps from [The Picture Org(anizer)](https://thepictureorg.com/tools), signed and notarized by The Picture Org LLC.

```sh
brew install thepictureorgllc/tap/sweepwell
```

| App | What it does | Price |
| --- | --- | --- |
| [Sweepwell](https://thepictureorg.com/sweepwell) | Finds and removes empty folders on photo drives | Free |

Apple silicon Macs, macOS 13 or later. More apps are added as they are listed. Paid apps run as a free 21-day trial,
then need a license key from [thepictureorg.com/tools](https://thepictureorg.com/tools#buy).
